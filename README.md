# 📚 Library Management System

**PHP | MySQL | HTML5 | CSS3 | XAMPP | phpMyAdmin**

A simple **Library Management System** developed using **PHP, MySQL, HTML, and CSS**.

## ✨ Features

- 🔐 Admin Login
- 📊 Dashboard
- 📚 Book Management
- 👤 Member Management
- 📖 Issue Books
- 🔄 Return Books
- 🔎 Search Books
- 📦 Available Book Tracking
- 🗄️ MySQL Database Integration
- 📱 Responsive Design

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| PHP | Backend |
| MySQL | Database |
| HTML5 | Frontend |
| CSS3 | Styling |
| XAMPP | Local Server |
| phpMyAdmin | Database Management |

## ⚙️ Installation

### 1. Install XAMPP

Install **XAMPP** and start:

- Apache
- MySQL

### 2. Copy the Project

Copy the `LibraryManagementSystem` folder to:

`C:\xampp\htdocs\libray\`

### 3. Setup Database

Open:

`http://localhost/phpmyadmin`

Go to **Import** and select:

`database/library_db.sql`

The database `library_db` will be created automatically.

### 4. Run the Application

Open:

`http://localhost/libray/LibraryManagementSystem/login.php`
